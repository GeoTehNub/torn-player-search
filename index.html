Torn API ToS: how this tool uses your key
  • Data storage: Only in your own browser (localStorage + IndexedDB): scan results, cached player/faction lookups, watchlist, notes, presets and, if ticked, your key. Nothing is sent anywhere except api.torn.com.
  • Data sharing: None. No server, no analytics, no third parties.
  • Purpose of use: Personal player search over public Hall of Fame / profile data.
  • Key storage & sharing: Kept locally only; never shared. Untick "Remember" to keep it in memory for this tab only.
  • Key access level: Public is enough. All endpoints used (torn/hof, user/{id} profile, job, personalstats, faction/{id}/basic) are public.
  • Rate limits: Throttled to your chosen budget (default 80/min, hard cap 100/min = Torn's per-user limit). It stops immediately on invalid-key or ban errors and backs off on "too many requests".
