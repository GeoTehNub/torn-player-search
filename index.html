Settings

Torn API key

A Public key is all this tool needs. Create one under Torn → Preferences → API Keys.

FFScouter (optional)

Adds more accurate stat estimates and Fair Fight. Your key must be registered at FFScouter first. Using it sends your key and the IDs of matching players to ffscouter.com. Sign up and read their Data Policy & Terms.

How your data is used

  • Storage: everything stays in this browser (scan results, looked-up details, watchlist, notes, saved searches and, if you allow it, your keys).
  • Sharing: no server and no analytics. The page talks to api.torn.com, and to ffscouter.com only if you use FFScouter.
  • Purpose: personal player search over public Hall of Fame and profile data.
  • Key access: Public. Every Torn endpoint used is public.
  • Rate limit: never more than your per-minute budget in any 60 seconds (hard cap 100). It pauses when Torn says “too many requests” and forgets a key that Torn rejects.

Shortcuts: Ctrl + Enter scan · Esc stop · / search names
