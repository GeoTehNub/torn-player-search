Settings

Torn API key

A Public key is all this tool needs. Create one under Torn → Preferences → API Keys.

Fair Fight (FFScouter)

Fair Fight tells you whether you can beat someone. It comes from FFScouter, which needs your key registered there first. Using it sends your key and the IDs of players you're checking to ffscouter.com. Sign up and read their Data Policy & Terms.

Used to judge fights when FFScouter has no number, by comparing with the rank-based estimate.

Watching

While this page is open, watched players are re-checked about every 30 seconds (1 call each). You're alerted when their bazaar stock drops (a sale just put cash in their wallet) or when they become attackable. Alerts only link to the attack page; you always click it yourself.

How your data is used

  • Storage: everything stays in this browser (found players, check results, watch list and, if you allow it, your keys).
  • Sharing: no server and no analytics. The page talks to api.torn.com, and to ffscouter.com only if you use Fair Fight.
  • Purpose: personal gain: finding players to mug, using public data only.
  • Key access: Public. Every Torn endpoint used is public.
  • Rate limit: never more than your per-minute budget in any 60 seconds (hard cap 100). It pauses when Torn says “too many requests” and forgets a key Torn rejects.
  • No automation: the tool never opens the attack page or attacks. Every attack is your own click.

Shortcuts: Ctrl + Enter find players · Esc stop
